# PHASE 6F.8 — LANGGRAPH THREAD_ID / OPTIMIZATION_RUN_ID APPROVAL FAILURE AUDIT

## 1. Executive Summary & Status
- **STATUS:** `ROOT CAUSE CONFIRMED`
- **Observed Error:**
  `400 Bad Request: "No active graph state found for thread_id='opt-b48a0315-3b45-4b43-94e1-728d4e8a04cd'"`
- **Core Root Cause:**
  The frontend and backend conflate two distinct domain identities:
  1. **LangGraph `thread_id`**: Checkpoint memory key generated during `POST /agents/run` (e.g., `thread-a1b2c3d4...`) used by LangGraph `MemorySaver` to pause/resume graph execution.
  2. **Optimization `optimization_run_id`**: OR-Tools allocation proposal ID generated by `AllocationService` (e.g., `opt-b48a0315...`) used to query allocations and governance status.

  The backend `AgentRunResponse` fails to return `thread_id` to the caller, and `get_incident_governance` only tracks `optimization_run_id`. Consequently, the frontend `dashboard.tsx` and `ApprovalExecutionPanel.tsx` mistakenly pass `optimization_run_id` (`opt-...`) as the `thread_id` parameter to `POST /agents/review/{thread_id}`, causing LangGraph checkpoint lookup to fail.

## 6. Minimal Recommended Correction Plan (DO NOT IMPLEMENT YET)

To establish a clean, type-safe contract without violating identity rules:

### 1. Update Backend API Schemas (`backend/app/api/schemas/internal.py` & `responses.py`)
Add `thread_id: Optional[str] = None` to:
- `AgentRunResponse`
- `IncidentGovernanceResponse`

### 2. Update Backend `AgentService` (`backend/app/services/agent_service.py`)
Return `thread_id` in `AgentRunResponse`:
```python
return AgentRunResponse(
    thread_id=thread_id,
    run_id=final_state.run_id,
    status=status,
    human_approval_state=final_state.human_approval_state,
    errors=errors
)
```

### 3. Update Governance Route & Approval Persist (`backend/app/api/routes/incidents.py` & `ml/src/agents/graph.py`)
- Include `thread_id` in `ApprovalRecord` or store `thread_id` in incident governance metadata so `GET /incidents/{id}/governance` surfaces both `optimization_run_id` and `thread_id`.

### 4. Update Frontend API Types & Components
- In `frontend/src/lib/api/types.ts`: Add `thread_id?: string | null` to `AgentRunResponse` and `IncidentGovernanceResponse`.
- In `frontend/src/routes/dashboard.tsx`: Bind `activeThreadId` to `governanceState?.thread_id || agentRunResponse?.thread_id`.
- In `frontend/src/components/dr/ApprovalExecutionPanel.tsx`: Separate `threadId` (used for `submitReview` & `executeProposal`) from `optimizationRunId` (used for allocation display).
